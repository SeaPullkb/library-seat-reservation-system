# M2 阅览室与座位管理测试记录

日期：2026-10-19（Asia/Shanghai）。环境：Temurin JDK 17、Maven 3.9.11、Docker、真实MySQL 8及Chromium。

## 自动化测试

命令：`./mvnw -B -ntp verify`。

结果：**39项执行，0失败，0错误，0跳过，BUILD SUCCESS**。
其中M1回归22项，新增 `SpaceIntegrationTest` 17项；两组测试分别使用Testcontainers隔离的真实MySQL实例，不改动开发数据库。

覆盖：

- 管理员创建、编辑、启用和停用阅览室，表单验证与失败后输入保留。
- 座位创建、编号修改、启停用和删除；客户端不能借参数改变所属阅览室或直接绕过启停用流程。
- 同室编号唯一，去除首尾空白后冲突及大小写冲突均被拦截；不同阅览室可有同名座位。
- 同室两个线程同时创建相同编号恰好一方成功。
- 阅览室容量取启用座位数；停用阅览室不覆盖座位自身状态，启用后恢复原配置。
- 当前或未来有效PENDING、USING阻止座位和整个阅览室停用；截止时刻仍有效；已超期待签到及过往已结束时段不阻止维护。
- 座位有预约历史不能删除，修改编号仍保留历史外键关联；无关联座位可删除。
- 五种预约状态、已经截止但尚未释放的PENDING、不同日期和时段的网格展示；COMPLETED仍占用，CANCELLED/EXPIRED不占用。
- 已释放记录和后续新记录同时存在时，网格不重复显示座位。
- 学生只能浏览开放阅览室，直访停用/不存在的阅览室返回404；非法日期、格式和时段返回400。
- 学生对全部管理写接口的越权请求被拒绝；管理写接口全部要求CSRF；跨阅览室伪造座位ID返回404且不修改原数据。
- 管理列表、创建和编辑弹窗、学生列表与网格的服务端渲染，以及用户输入HTML转义。
- 未登录可访问本地JavaScript资源，避免登录页脚本被认证跳转替换。
