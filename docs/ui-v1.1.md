## 设计与实现约定

- 采用蓝色导航、浅灰背景、白色面板。间距、边框、颜色、圆角来自统一 CSS 变量。
- 首页先呈现当前任务和真实指标，次要说明放在紧凑规则面板。
- 表格允许局部横向滚动，整页不能横向溢出；手机按钮至少 44px 点击高度。
- 文字与图标共同表达状态；键盘焦点可见；保留原表单、路由、CSRF 和服务端鉴权。
- 预约余座与使用率区别显示：已完成记录继续锁定原日期时段，但不计为“正在使用”。
- 所有生产页面指标查询现有四表。演示夹具必须独立、可重建、与演示时钟一致。
- 每项独立提交并记录相关构建、测试和桌面/手机实际浏览器结果；截图不能替代操作测试。
